# TransferKit — робочий чекліст

Джерело вимог: [`PROJECT_SPEC.md`](PROJECT_SPEC.md). Це виконавчий чекліст реалізації повного продукту TransferKit, від контрактів до документації й перевірок.

## Правила виконання

- Іти за пунктами зверху вниз і ставити `[x]` лише після фактичного виконання.
- `[ ]` — не зроблено; `[~]` — частково зроблено або очікує зовнішньої перевірки.
- Для пункту, який неможливо завершити без фізичного пристрою/зовнішнього середовища, записувати конкретну залежність і не видавати його за виконаний.
- Базові припущення з §3.3 ТЗ: minSdk 26, без root, Shizuku опційний, sideload. Продукт локальний, без телеметрії.
- Суперечність обсягу: §3.3 називає MVP Tier A+B+D+E, а M1 — A+B. Реалізацію вести по M1–M5; критерій MVP продукту з §3.3 лишити цільовим обсягом першого релізу, окремо фіксуючи фактичний стан кожного Tier.
